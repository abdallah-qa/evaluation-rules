# Vaultinum KYS QA Rules Test Files

## File Naming Convention

Test files should follow a specific naming pattern to clearly indicate their purpose and expected behavior.

### Pattern convention

maintenability|security|open-source/
└─ rule_name/
    ├─ match/
       └─ default-[occurrence].extension
    ├─ no-match/
       └─ default-[occurrence].extension
    └─ third-party/
        └─ default-[occurrence].extension
